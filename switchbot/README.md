## 事前準備

### 1. 対象のシーンについて

実行するのは、SwitchBot アプリの **ホーム画面「よく使うシーン」にある「下上」** です。
ここに並んでいるのはタップで実行する **手動シーン** なので、API から実行できます。
特別な作り直しは不要です。

（補足：API から実行できるのは手動シーンだけです。「〇〇したら△△する」という
条件付きの **オートメーションは API から起動できません**。将来ほかのシーンを
足す場合はこの点に注意してください。）

### 2. トークンとシークレットを取得する

SwitchBot アプリで:

1. 右下「プロフィール」→「設定」
2. 「アプリバージョン」を **10回連続でタップ** → 「開発者向けオプション」が出る
3. 「開発者向けオプション」を開き、**トークン** と **クライアントシークレット** をコピー

### 3. GitHub にシークレットとして登録する

リポジトリの `Settings` → `Secrets and variables` → `Actions` → `New repository secret` で:

| Name | 値 |
| --- | --- |
| `SWITCHBOT_TOKEN` | 上で取得したトークン |
| `SWITCHBOT_SECRET` | 上で取得したクライアントシークレット |

トークンは他人に渡さないでください。GitHub のシークレットに入れた値はログに出ません。

### 4. 動作確認

`Actions` タブ →「SwitchBot「下上」を25分ごとに実行」→ `Run workflow` で手動実行できます。
成功すれば、以後は上のスケジュールで自動的に動きます。

## 手元で実行する場合

```bash
export SWITCHBOT_TOKEN=xxxx
export SWITCHBOT_SECRET=yyyy

# 登録されている手動シーンの一覧を見る
python3 switchbot/run_scene.py --list

# 「下上」を実行する
python3 switchbot/run_scene.py --scene 下上
```

## 注意点

- **時刻は多少ずれます。** GitHub Actions のスケジュール実行は混雑時に数分〜十数分
  遅れることがあり、まれにスキップされます。分単位の正確さが必要な用途には向きません。
- スケジュールは UTC で書かれています（JST − 9時間）。夏時間はないのでずれません。
- 実行間隔を変えたい場合は `.github/workflows/switchbot-shita-ue.yml` の
  `cron` を編集してください。コメントに JST との対応を書いてあります。
- リポジトリが 60 日間何も更新されないと、GitHub がスケジュール実行を自動停止します。
  停止した場合は `Actions` タブから再度有効化してください。
