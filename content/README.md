# コンテンツ運用ルール

建設業（解体・専門工事）の実務 × 生成AI をテーマにした、記事と動画の制作・公開ルール。

## 何を作るか

1本の案件から、次の4つを1ファイルで作る。**記事本文がそのまま動画の台本になる**構成にしているので、書き直しは発生しない。

| 出力 | 用途 | 尺・分量 |
|---|---|---|
| 記事本文 | 自サイト・note | 2,500〜3,500字 |
| 長尺動画 | YouTube | 記事本文を読む（6〜9分） |
| ショート台本 | YouTube Shorts / TikTok / Reels | 55〜70秒 |
| SNS投稿文 | X / Instagram | 各1本 |

フォーマットの詳細は `FORMAT.md`。

## 公開前チェック（毎回、例外なし）

記事を公開する前に、この6項目を必ず人が確認する。ここを飛ばすと、自動化パイプラインがそのまま事故製造機になる。

### 1. 匿名化

**素になった案件の以下は、いかなる形でも公開しない。**

- 発注者・元請の社名（例：`estimate-sinwa-canopy.xlsx` の「信和ホームズ㈱」「熊谷組」）
- 現場の住所・地番（「神奈川県横浜市都筑区茅ケ崎南 3-23-5」→ 公開時は「横浜市内」まで）
- 立会者・担当者の実名と役職（「専務 藤井 様」「社長 古谷 様」「会長 園尾 様」→ 記載しない）
- 建物の外観が特定できる看板・社名入りサイン（写真は該当部をマスク）

**公開してよいのは、寸法・数量・工種・工法・判断の過程だけ。**これが記事の価値そのものであり、匿名化しても一切失われない。

### 2. 金額

単価・金額は原則載せない。載せる場合は実額ではなく**構成比（%）または帯（〜50万／50〜100万）**にする。
※ 現行の `estimate-sinwa-canopy.xlsx` は単価未入力のため、数量のみの引用は問題ない。

### 3. 法令に関わる記述

石綿、道路使用許可、廃棄物処分の区分など、法令に触れる記述は**断定しない**。
- ✅ 「レベル3に該当する場合は〜」「分析結果により区分する」
- ❌ 「ケイカル板はレベル3なので〜」

判断の主体は常に有資格者であり、記事はその判断過程の記録という位置づけを崩さない。

### 4. 数値の裏取り

記事に出る寸法・数量は、必ず `数量根拠` シートの実測値と突き合わせる。
**仮定値（未測定のまま仮に置いた値）は、記事でも必ず「仮定」と明記する。**記事の中で仮定が既成事実になるのが、この種のコンテンツで最も起きやすい事故。

### 5. PR表記

アフィリエイトリンクを含む記事・投稿は、**冒頭に「PR」または「広告を含みます」を明示**する。景品表示法のステマ規制（2023年10月施行）の対象。動画は概要欄と、動画内テロップの両方に入れる。

### 6. 体験していないことを書かない

「使ってみた」と書けるのは、実際に自分の案件で使ったものだけ。AIに体験談を生成させない。これはステマ規制と、Google のスパムポリシー（大量生成コンテンツの不正使用）の両方に直撃する。

## 収益導線

記事ごとに1本だけ置く。複数置くと成果が分散し、記事も読みにくくなる。

| 記事のテーマ | 導線 |
|---|---|
| 見積・積算の効率化 | 建設業向け見積／原価管理SaaS、生成AIツール |
| 書類作成（安全書類・施工計画書） | AI-OCR、電子契約、建設業向け業務システム |
| 図面・現調 | 測量／点群、CADツール、現場カメラ |
| 費用・相場の実例 | 解体・リフォーム一括見積サービス |
| 資格・人材 | 施工管理・解体施工技士などの講座 |

## 撮影・素材

動画の素材は**現場写真と画面録画で足りる**。顔出し・喋りは不要。
- 現場写真：着工前／施工中／完了（既存の `photo-sheet.html` がそのまま素材整理に使える）
- 画面録画：Excel の数量根拠シート、AI とのやりとり画面（社名・住所はマスク）
- 図面：`demolition-plan-*.html` の該当部を切り出し
