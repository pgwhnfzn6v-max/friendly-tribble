## 現場写真の印刷（カラー）

`photo-sheet.html` … 手元の写真ファイルを選ぶと、A3横（A3縦/A4も可）のカラー写真シートに並べて印刷できるページ。

使い方
1. `photo-sheet.html` をダブルクリックしてブラウザで開く
2. 「写真を選ぶ」で写真をまとめて選択（ドラッグ＆ドロップも可）
3. 現場名・撮影日・用紙・1枚あたりの枚数（2/4/6/9）を選び、各写真の説明を記入
4. 「印刷（カラー）」→ 余白：なし／背景のグラフィック：ON／カラー　※「PDFとして保存」でPDF化も可

写真は選んだ端末の中だけで処理され、どこにもアップロードされません。
