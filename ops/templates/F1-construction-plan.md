## 1. 工事概要

前方パネル（ケイカル板）一部4面、後方パネル1面、奥のルーバーおよび下地（鉄骨アングル）を撤去する。取合い部のシールは本体撤去に先行して撤去する。撤去後は鉄骨あらわしの状態とする。

## 2. 施工条件

- 建物は**営業中**。作業前後に駐車車両の移動および場内調整を行う
- 道路側：高所作業車（スカイマスター等）
- 敷地内：ローリングタワー
- 撤去後は鉄骨あらわし。仕上げ復旧は本工事に含まない

## 4. 安全管理

### 主要リスクと対策

| リスク | 対策 |
|---|---|
| 高所からの墜落 | 高所作業車・ローリングタワーの適正使用、要求性能墜落制止用器具の使用、点検表による日常点検 |
| 撤去材の落下 | 落下範囲の立入禁止措置、玉掛けによる吊下し、下部への監視員配置 |
| 第三者災害（営業中・歩道） | 作業区画の明示、歩行者誘導員、作業時間帯の調整 |
| 火災（溶断） | 消火器配置、火の粉養生、作業後の残火確認 |
| 石綿ばく露 | 事前調査結果に基づく措置。**含有判明時は本計画書を改訂** |
| 車両との接触 | 誘導員配置、車両移動を作業前に完了させる |
