# マニフェスト返送管理（H3）

> AI適用度 ◎（完全自動化してよい）／ マニュアル優先度 A
> 期限管理は人の記憶で回してはいけない。抜けると法令違反になり、しかも抜けたことに気づけない。

## 返送期限

| 区分 | 期限 | 起算 |
|---|---|---|
| B2票（運搬終了） | 90日以内 | 交付日 |
| D票（処分終了） | 90日以内 | 交付日 |
| E票（最終処分終了） | 180日以内 | 交付日 |
| 特別管理産業廃棄物（石綿含有等） | **60日以内** | 交付日 |

**保存期間：5年**（交付者控え・返送票とも）

※ 上表は一般的な区分。実際の運用区分は契約している処理業者と自治体の指導に合わせて確認すること。

## 自動化する部分

交付日と区分を入れたら、期限3種が自動計算され、期限14日前・7日前・当日に通知が飛ぶ状態にする。ここは完全に機械の仕事で、人の判断は一切入らない。

```
入力：交付No / 案件 / 交付日 / 廃棄物区分 / 特管フラグ
出力：B2期限・D期限・E期限、残日数、アラート
条件：特管フラグ = 要 → 60日、それ以外 → B2/D 90日、E 180日
```

Excel でも組めるが、通知まで含めるならスプレッドシート＋スクリプト、または電子マニフェストへの移行が早い。
